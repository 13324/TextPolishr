## Handy — major inspiration and adapted implementation work

Text Polishr owes a substantial debt to **Handy**, created by CJ Pais:

- Website: https://handy.computer
- Source: https://github.com/cjpais/Handy
- Copyright: Copyright (c) 2025 CJ Pais
- License: MIT

Handy's implementation and product design strongly informed Text Polishr's
system-wide workflow. In particular, Text Polishr's Windows clipboard
transaction, delayed-rendering approach, clipboard restoration safeguards,
provider configuration, and LLM post-processing architecture are inspired by
and partially adapted from Handy's source code.

Handy is an excellent open-source voice dictation and transcription tool. Text
Polishr is a narrower selected-text transformation utility; it does not claim
to have independently invented the underlying insertion and post-processing
ideas that Handy demonstrated so well.
